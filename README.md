# CyberEscape
Un pirate a pris le contrôle du serveur et tu es enfermé dedans. Pour t'en sortir, tu dois traverser des salles piégées où chaque porte cache une énigme de cybersécurité : un mot de passe dans le code source, un message chiffré...
L'arme ? Les cyber-cartes. Tu les ramasses en explorant, chacune t'apprends une vraie notion de cyber, et ce sont elles qui te donnent les clés pour avancer.
Pas besoin d'être expert : tu apprends en jouant.
